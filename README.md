# SCHEMAX

SCHEMAX is a powerful tool for visualizing and generating database schemas.

## Getting Started

### Prerequisites

- Node.js 20+
- Docker (optional)

### Development

1.  Install dependencies:
    ```bash
    pnpm install
    ```

2.  Run the development server:
    ```bash
    pnpm dev
    ```

### Docker

To build and run the application using Docker:

```bash
docker-compose up --build
```

The application will be available at `http://localhost:3000`.
